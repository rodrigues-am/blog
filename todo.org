* NOTAS TÉCNICAS

** Sincronia com ox-hugo
O =blog.org= é a fonte canônica. Os arquivos =content/*.md= são gerados pelo
ox-hugo. Alterações na estrutura do blog.org (about, archives) serão
re-exportadas. As alterações de config.yml e layouts/ NÃO são afetadas pela
exportação ox-hugo.

Arquivos seguros de editar diretamente (não sobrescritos pelo ox-hugo):
- =config.yml=
- =layouts/partials/*=
- =layouts/_default/*=
- =static/*=
- =netlify.toml=

Arquivos gerados pelo ox-hugo (NÃO editar diretamente):
- =content/posts/*=
- =content/about.md=
- =content/archives.md=

** Instalação do ox-hugo no server
Para testar a exportação, é necessário instalar o pacote =ox-hugo= no Emacs.
O Emacs 30.2 já está disponível. O ox-hugo pode ser instalado via:
- =package-install= (MELPA)
- Ou adicionando ao config do Doom Emacs

** Schema no PaperMod
O template =schema_json.html= do PaperMod usa:
- =site.Params.schema.publisherType= (default: "Organization")
- =site.Params.schema.sameAs= (array de URLs)
- Se =schema.sameAs= não definido, usa =SocialIcons= (não =social=)

O BlogPosting schema é automaticamente gerado para páginas (= .IsPage =).
